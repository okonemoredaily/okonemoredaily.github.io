Privacy policy

Last updated: November 4, 2026

"ok one more" publishes daily puzzle videos on Instagram and YouTube. This policy covers the small upload tool ("ok one more poster") we use to post those videos, and these web pages.

What the tool does

The tool uploads videos we make ourselves to our own YouTube channel and our own Instagram account. It only ever signs in to accounts we own.

What data it uses

  • Google / YouTube: the tool asks for permission to upload videos to our YouTube channel (the youtube.upload scope). It does not read, collect or store anyone else's data, and it does not access viewers' information.
  • Sign-in tokens are stored only on our own computer so the tool can keep uploading. They are never shared or sent anywhere except to Google and Meta when uploading.
  • We do not sell, share or transfer any data to third parties, and we do not use it for advertising.

These web pages

These pages are hosted on GitHub Pages. We don't run analytics, cookies or trackers on them. GitHub may keep standard server logs; see GitHub's privacy statement.

Google API Services User Data Policy

Our use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
